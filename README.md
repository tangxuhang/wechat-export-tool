# 微信成员与聊天记录导出工具

Windows 11 x64 桌面工具。可把本机可读的群成员名单导出为 Excel，把选定好友或群聊的消息导出为离线 HTML、TXT 和本机已有的附件。

## 下载和运行

1. 在仓库的 **Releases** 下载 Windows x64 ZIP，完整解压。
2. 登录本机电脑版微信，运行解压目录中的 `发布版/微信群成员导出.exe`。保留同目录的两个引擎和语音模型。使用者无需安装 Python。
3. 在对应页签选择账号、群聊或好友，先预览，再导出。

## v1.2.5

- 自动识别 Windows 的当前“文档”目录，包括已重定向到其他磁盘的目录。
- 顶部 **微信数据目录 → 选择目录…** 可选择 `xwechat_files` 或其上一级。两个页签共用这次选择。重启后恢复自动查找，也可手动恢复。
- 账号为空时，聊天页的 **刷新会话** 会重新搜索账号。

账号能否读取及可导出的日期、附件范围取决于电脑版微信版本和本机缓存。软件不会上传聊天内容。请自行保管导出的文件。
